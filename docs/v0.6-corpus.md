# V0.6 corpus prerequisite — 5 GiB streamed file and 50,000 small files

Status: prerequisite smoke passed; V0.6 beta qualification is not established.

## Command

```text
python scripts/v06-corpus-smoke.py --binary ./peervault --backend .tools/restic \
  --source-root <new-source-and-repository-root> --restore-root <new-restore-root>
```

The script creates:

- one 5 GiB zero-filled file, written in 1 MiB chunks;
- 50 directories with 1,000 deterministic 128-byte files each (50,000 files);
- a source manifest, capture, repository full read and exact restore;
- a time limit of 900 seconds, repository limit of 8 GiB and an explicit
  "RSS not measured" limit note.

## Observed — 2026-11-01

Windows 11/NTFS, source/repository on G: SATA HDD, restore on F: SATA SSD:

The restored tree matched every path, size and SHA-256. The zero-filled large
file deduplicates heavily, so the repository size is not a representative
dedup/disk-usage measurement.
